# Express Blog Backend

Server back-end per la gestione di un blog, sviluppato con Express.

## Rotte

- `GET /` → Server del mio blog
- `GET /posts` → Lista dei post
- `GET /posts/:id` → Dettaglio del post
- `POST /posts` → Creazione del post
- `PUT /posts/:id` → Aggiornamento del post
- `DELETE /posts/:id` → Cancellazione del post

## Static assets

I file statici sono serviti dalla cartella `public`.
